# Cherry Markdown: важные изменения настроек загрузки

**PicGo по-прежнему поддерживается, загрузка binary не изменена.** Настройки не переносятся, не переписываются и не удаляются автоматически.

## Что нужно проверить?

- Старые `UploadType`, `PicGoServer` и устаревшие значения режима больше не читаются. Используйте настройки ниже.
- В рабочих областях с несколькими папками теперь действуют настройки папки документа. Проверьте адрес и источник настроек внизу предпросмотра.
- Настройки загрузчика берутся целиком из одного уровня. Адрес проекта больше не наследует заголовки авторизации пользователя.
- Неверный режим, URL, имя поля или каталог останавливает загрузку без переключения адреса или протокола.
- Старый `Theme` больше не читается и не переносится. Используйте текущие настройки темы; сохранённая ручная тема остаётся доступной.

В ограниченном режиме доступны пользовательские настройки загрузки. Настройки проекта требуют доверия через штатное окно VS Code Workspace Trust. Не сохраняйте секреты в репозитории.

## Настройка PicGo

Настройте хостинг изображений в PicGo 2.4.0+, включите HTTP-сервер и вручную задайте настройки VS Code (при необходимости измените адрес):

```json
{
  "cherryMarkdown.ImageUploadMode": "remote",
  "cherryMarkdown.CustomUploader": {
    "enable": true,
    "url": "http://127.0.0.1:36677/upload",
    "format": "multipart",
    "fieldName": "files",
    "headers": {}
  }
}
```

Расширение отправляет содержимое файла и автоматически создаёт границу и длину multipart. При необходимости добавьте `Authorization` в `headers`. В Remote SSH, контейнере или WSL адрес `127.0.0.1` относится к среде хоста расширения — проверьте доступность PicGo.

Существующие загрузчики binary могут сохранить настройки: без `format` используется `binary`. Ошибка сервера не переключает протокол.

## Повторится ли уведомление?

Эта заметка показывается автоматически один раз в профиле VS Code, даже если её закрыть. Перезагрузка окна и обычные patch-релизы не повторяют её. При первом выпуске функции невозможно надёжно отличить установку от обновления, поэтому уведомление один раз увидят обе группы.

Записывается только внутреннее состояние уведомления, а не настройки пользователя. Предупреждения о неверной конфигурации при загрузке сохраняются. Откройте эту страницу повторно командой **Cherry Markdown: Просмотреть изменения**.
