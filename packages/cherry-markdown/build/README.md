# 公共构建配置

此目录的公共模块只复用构建配置和转换，不承载编辑器、图表、语法解析等业务逻辑。

| 模块              | 使用方                              | 公共职责                                                                               |
| ----------------- | ----------------------------------- | -------------------------------------------------------------------------------------- |
| `library.js`      | Cherry 主包、附加插件、小程序       | 库入口与格式配置、固定文件名、单文件输出、基础目标与压缩默认值，保留多次构建的已有产物 |
| `prism.js`        | Cherry Vite 插件、Milkdown 生成脚本 | 单一语言清单、Babel 依赖与别名加载、限定于 Prism core 的全局变量兼容转换               |
| `prism.plugin.js` | Cherry 开发、测试和发布构建、小程序 | 将公共 Prism 转换接入 Vite 与依赖预构建流程                                            |

`createLibraryBuild(output, overrides)` 通过 Vite 的 `mergeConfig` 合并包内配置。包内继续声明入口矩阵、外部依赖、别名、全局名称、版本注入及格式兼容设置；主包保留 Terser/ES5 约定，附加插件保留各自的 UMD 全局名称，小程序保留 Sanitizer 替换。公共模块不引入业务源码。

Milkdown 保留 TypeScript 发布流程与独立高亮运行时生成流程，仅共用 Prism 转换。VS Code 插件的 Node/CJS 扩展与浏览器 Webview，以及客户端、演示站点的应用构建，继续使用各自配置；运行环境、资源输出和拆包策略不同，不强制套用单文件库模式。
