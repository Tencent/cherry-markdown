# Security Policy

## Supported Versions

Security updates are applied only to the latest release.

## Reporting a Vulnerability

If you have discovered a security vulnerability in this project, please
report it privately. **Do not disclose it as a public issue.** This gives us
time to work with you to fix the issue before public exposure, reducing the
chance that the exploit will be used before a patch is released.

Please disclose it through a [security advisory](https://github.com/Tencent/cherry-markdown/security/advisories/new).

Alternatively, you may contact the group owner privately in QQ group
`768057131`.  As a reminder, please do not share a dangerous vulnerability
with anyone else or distribute it publicly.
