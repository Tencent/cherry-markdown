# 移动端实际渲染对照

Web 与原生页面共同导入 `src/fixtures/mobile-parity.ts` 的 `MOBILE_PARITY_MARKDOWN`，没有为任一端改写内容。Web 使用真实 Cherry 的 previewOnly 模式和发布 CSS；小程序使用原生组件。对照页面只统一承载区的宽度和内边距，不覆盖 Web 文档内部样式。

## 复现

1. 在仓库根目录构建核心包、小程序包和示例：`vp run build:core`、`vp run build:miniProgram`、`vp run -F @cherry-markdown/mini-program-demo build`。
2. 运行 `vp run -F @cherry-markdown/mini-program-demo compare`，打开输出地址。页面内的 iframe 提供 390px Web 视口；也可以直接打开 `?document=1` 并将浏览器视口设置为 390×844。
3. 开发者工具打开 `examples/miniProgram`，添加编译模式 `pages/parity/index`。选择 iPhone 12/13 模拟器，确认实际渲染模式为 Skyline。
4. 两端逻辑视口均为 390px、左右内边距各 20px，正文宽度为 350px。原生的状态栏/胶囊按钮不属于文档对照范围。
5. 深色主题：Web 使用 `?document=1&theme=dark`；原生编译查询参数使用 `theme=dark`。不要将模拟器的截图像素宽度当作逻辑视口宽度。

## 本轮结果（2026-10-27）

环境为 macOS 上的 Chromium 与微信开发者工具 RC 2.02.2607161，基础库 3.17.4、Skyline 1.4.21。以下为实际 DOM/native selector query 读数，单位为逻辑 px，不是从截图估算：

| 对照项 | Cherry Web | 原生修正后 |
| --- | ---: | ---: |
| 一级标题顶部 | 50 | 50 |
| 一级标题高度 | 35.20 | 35 |
| 第二段正文顶部 | 195.70 | 197 |
| 二级标题顶部 | 277.70 | 279 |
| 引用框顶部 / 高度 | 456.05 / 98.5 | 459 / 98 |
| 无序列表高度 | 130 | 130 |
| 有序列表高度 | 52 | 52 |
| 分隔线顶部 | 855.28 | 855 |
| 字号扩展段落顶部 / 高度 | 872.28 / 28.5 | 872 / 29 |
| 面板高度 | 89.5 | 89 |
| 收起详情高度 | 52 | 52 |

原生无序列表原先高 222.6px、有序列表高 103px：除间距差异外，终止换行被原生 text 多显示为一行。修复只发生在原生呈现阶段，保留共享语义及真实空行。标题恢复 Web 的 2/1.5/1.25/1/0.875/0.85em 层级与主题颜色；引用框、嵌套列表标记、代码字号/间距、高亮别名、面板及详情分别对齐 Web 样式规则。

深色切换曾使 Skyline 跨组件继承的文字颜色失效，现改为显式传递正文、标题和面板的颜色变量。面板和默认 Prism 色值从既有 Sass 提取，没有维护第二套颜色表。原生组件不加载额外字体文件。

主题提取只采用真实 previewOnly DOM 生效的根选择器。当前 Web 预览类名为 `cherry-markdown dark`，因此 Sass 中要求 `cherry-markdown theme__dark` 的面板覆盖未生效：原生默认跟随实际 Web 的蓝色信息面板，没有自行启用紫色面板覆盖，也没有在本 PR 修改 Web 主题行为。

## 仍然存在的差异及验收边界

- Skyline 的字形、行盒及小数像素取整与 Chromium 不同；英文长词的断行、行内 code 的描边仍可能不同。没有将测量偏移写成专用补偿值，也不宣称逐像素相同。
- Web 代码容器作为 inline-block 产生额外基线间隙；本样例表格及后续块顶部约差 7px。原生代码保持单行源码不折行、可横向滚动，复制按钮保留原生交互。
- Web 使用表格自动布局；原生使用接近 Web 最小单元格宽度的弹性列，列宽分配仍有差异。多行单元格按 Web 的垂直居中规则对齐，过宽表格保留横向滚动。
- Web 标题锚点图标、面板图标字体没有直接移植；任务状态使用原生文本/边框绘制，避免依赖 emoji 字形。
- 详情展开布局通过组件方法验证；本轮自动化对 Skyline 的模拟点击未稳定生效，不能视为触控事件链验收通过。
- 这次对照覆盖 390px 和默认/深色主题，不代表所有主题、宽度或 iOS/Android 真机。公式、Mermaid 等能力边界仍见小程序 README。
