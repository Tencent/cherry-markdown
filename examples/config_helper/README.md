# Cherry Markdown 配置生成器

这是 [Cherry Markdown](https://github.com/Tencent/cherry-markdown) 的可视化配置页面。选择常用配置后，可以立即查看编辑器效果，并复制完整配置代码用于自己的项目。

## 功能

- 按分类浏览或搜索常用配置项，调整开关、文本、选项和工具栏按钮。
- 使用默认配置、精简模式、完整模式或纯预览四种预设快速开始。
- 在实时预览中查看配置效果；在“完整配置代码”中查看修改位置并复制代码。
- 通过“导出配置”获取完整配置，包含原有的回调等参数，避免分别维护两份配置。
- 在“配置参考”中查看 Cherry.config.js 原文件及注释。

页面面向 GitHub Pages 等静态网站。上传和回调函数不提供可视化编辑控件，但会保留在导出的完整配置中。
