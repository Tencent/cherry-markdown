fix(milkdown): 修复编辑、渲染和接入中的稳定性问题

修复代码中类似脚注的文字影响真实脚注编号的问题，并保留自闭合脚注的现有行为。
修复删除脚注引用后其余编号和对应定义没有更新的问题；未引用的定义仍可编辑，且不会跳转到其他脚注。
修复外部更新提交后源码比较失败时，编辑器读取值和旧内容恢复信息可能落后的问题。

修复编辑或复制带脚注文档时，脚注布局占位可能被写入为额外换行的问题，同时保留用户输入的空段。
修复外部 HTML 粘贴时可能将真实空段误识别为脚注布局占位的问题。
修复部分结构编辑撤销后，标题和引用链接的原始写法无法恢复的问题；只有历史源码与当前完整文档匹配时才恢复。
减少销毁后的编辑器被依赖暂时缓存时对接入方引擎、回调和上传资源的持有。
减少迟到渲染清理结束后对错误回调的持有，并保留清理失败报告。

修复自定义 Engine 返回的图片和表情内容未清洗事件属性、SVG 动画可能改写链接的问题，并修复使用 esbuild 默认优化时编辑器可能无法启动、格式错误的页面锚点导致异常，以及点击编辑器外空白处不能关闭链接浮层的问题。标题含无法编码的 Unicode 字符时保留内容和目录文字；返回的 HTML 中的 SVG SMIL 动画元素会被移除。

修复自定义 Engine 返回的内联样式可通过 CSS 转义绕过 URL 检查的问题。
阻止自定义 Engine 内联样式通过 CSS 变量和 `image-set()` 发起未预期的外部请求。
使自定义 Engine 输出中的链接遵循 Cherry 对 `data:` 协议的限制，同时保留图片数据地址。
修复用户输入后静默回写相同内容会丢失待发送变更通知的问题。
修复外部文档更新触发插件同步再次更新时，页面内容与读取值或变更通知可能不一致的问题；较新更新解析失败时保留已成功应用的内容。
外部文档更新前先校验目标内容的序列化，避免序列化已失败时覆盖本地输入或取消待发送的变更通知。
外部更新没有改变文档结构时避免重复序列化，同时保留正常通知和失败后的本地输入。
外部更新提交后序列化失败且文档未被插件额外修改时，恢复原编辑器状态、输入和撤销；若插件已修改文档，则避免覆盖其内容并在序列化恢复后重新同步读取值和通知，错误回调可读取更新前的本地内容供应用保存，避免将可识别的编辑器内部尾部写入恢复结果；已同步内容以及可预先保存的未同步内容在序列化器仍故障时也可读取。
创建编辑器失败时，即使错误回调自身抛错，也保留原始创建错误并完成已初始化资源的清理。
异步序列化失败时隔离错误回调自身的异常，避免产生未捕获页面错误；序列化恢复后可继续编辑并接收变更通知。
修复销毁前序列化时再次调用销毁可能重复清理的问题。
修复本地输入序列化失败后恢复并立即销毁时，读取值仍是旧快照的问题。
销毁快照时若同步发生新编辑，重新尝试保存；持续变化无法保存时报告错误并完成清理。
修复外部更新期间插件同步销毁编辑器时，销毁后的读取值可能落后的问题，并在文档未被额外修改时保留原始格式，包括最终序列化阶段。
修复外部更新的最终序列化过程中同步修改文档时，读取值和变更通知可能落后的问题。
修复外部更新触发插件追加内容时，读取值和通知可能缺少插件内容的问题。
修复插件视图在文档提交后抛错时，读取值和通知可能停留在旧内容的问题；错误回调可读取更新前的本地内容。
修复插件追加事务抛错时，编辑器状态上下文与实际文档可能不一致的问题。
外部更新未被编辑器应用时保留原始内容和待发送的本地通知，并报告错误。
修复部分无序列表在输入和撤销时丢失原始列表标记的问题。
修复本地序列化失败后可能发送较旧通知的问题；恢复后读取可同步最新内容，序列化重入时不覆盖较新修改。
修复自定义渲染器的清理回调同步触发新文档更新时，旧预览可能覆盖最新结果的问题。
修复失败渲染的取消回调同步启动新渲染或销毁编辑器后，旧错误仍可能上报和覆盖界面的问题。
修复嵌套表格图表渲染回调同步替换文档时，更新被外层事务覆盖及过期图表继续启动的问题。
阻止编辑器已请求销毁后，尚未开始的图表渲染继续执行。
阻止编辑器销毁期间的图片上传回调和表单提交修改旧界面或文档，确保待处理上传被取消。
修正上传接入示例，返回异步任务以便编辑器显示上传失败并允许重试。
隔离自定义 Engine 清理回调的异常，避免中断其他节点的资源释放。
修复延迟复制完成后，在已切换的链接或已修改的代码上显示过期反馈的问题。
避免较早的复制请求失败后，通过回退操作覆盖后发起的复制内容。
修复导入或粘贴危险协议链接时，链接面板可能重新暴露可执行地址的问题；不安全链接仍可编辑修正。

修复图片上传期间外部更新在图片前插入内容时，上传完成后保存按钮可能保持禁用的问题；图片被外部替换时取消原上传，避免覆盖新内容。

修复上传期间手动修改图片地址可能被迟到的上传结果覆盖，以及更换地址后仍应用旧上传属性的问题。

图片地址为空时给出提示并将焦点定位到地址输入框，方便修正后保存。

修复粘贴单行格式文本时边界空格可能丢失、导致相邻文字连在一起，以及粘贴无格式文字时可能打断光标处原有格式的问题。

修复在末尾没有换行的文档末尾粘贴表格并撤销时，可能意外添加末尾换行的问题。

修复输入新段落后撤销时，可能无法恢复原始文档末尾换行的问题。

修复使用 CRLF 换行的文档在编辑或撤销后可能变成 LF 换行的问题。

修复复合内容中输入法组合期间收到外部文档更新时，可能意外增加末尾换行或混用换行格式的问题。

修复在 Panel 等复合内容中使用鼠标拖选文字后，选区偶尔立即消失的问题。

修复拖选跨段落文字时格式工具栏提前出现、遮挡拖选路径的问题。

修复 Firefox 中编辑器失焦后点击其他段落，输入可能落入原有链接或旧光标位置的问题。

修复触屏点击编辑器外部后，延迟出现的链接浮层可能遮挡下一次输入的问题。

移除自定义 Engine 输出中的样式表，避免 SVG 内嵌样式影响编辑器之外的页面；显式注册的图表渲染器保留所需样式，需由应用信任。

限制 Engine 输出中可能遮挡页面的固定、粘性和绝对定位，保留 Cherry 所需的相对定位。

提高不同主题下编辑弹窗主要操作按钮文字的对比度。

为编辑弹窗按钮恢复明显的键盘焦点提示。

为文字、链接和图片工具栏的按钮增加独立焦点轮廓，避免焦点与已启用状态混淆。

支持选中图片后通过 `Alt+F10` 进入图片操作栏，使用键盘切换和执行操作。

图片滚出视口时，键盘进入操作栏会先滚动到选中的图片，且不会产生内容变更通知。

图片仅有透明度动画时保持操作栏可用；可能改变位置或尺寸的有限动画仍等待稳定后再显示控件。

图片持续移动时保持操作栏跟随，并在移动期间隐藏缩放手柄以避免误操作。

图片被选中后才开始移动动画时，操作栏也会及时跟随；取消选择或销毁编辑器后停止观察。

暂停的图片动画调整进度后同步工具位置；若拖拽缩放时进度改变，则取消该次缩放，避免写入错误尺寸。

拖拽缩放时若外部启动位置或尺寸动画，也会取消该次缩放；缩放本身的宽高过渡仍可正常使用。

修复焦点位于编辑器外时图片控件仍拦截 Escape 键，以及 Firefox 中切回编辑器后无法重新选择同一图片的问题。

修复点击编辑器外部后图片工具栏仍然显示、可能遮挡宿主页面控件的问题。

修复从图片工具栏按 Escape 退出时焦点丢失，以及同一编辑器容器内的其他控件可能被图片控件拦截 Escape 的问题。

修复拖动行内图片到文字中时落点错误并产生空段落的问题。

修复触摸图片尺寸手柄时手势可能被浏览器滚动接管，导致无法调整大小的问题。

修复多点触摸时第二根手指可能接管图片缩放的问题。

修复点击图片尺寸手柄但未调整大小时仍改写 Markdown 的问题。

修复编辑器创建后的初始序列化失败时，插件资源未清理且未报告创建错误的问题。

修复并发调用销毁时，后续调用可能在插件异步清理结束前返回的问题；插件清理失败时尽可能释放编辑器视图，并保留原始错误。

修复同步编辑后立即销毁时，最后一次修改可能未反映在 `getMarkdown()` 结果中的问题。

修复图片编辑时页面滚动或窗口大小变化会关闭表单并丢失未保存输入的问题。

修复图片缩放过程中外部在图片前插入内容时尺寸修改可能丢失的问题；图片被替换时取消原缩放，避免修改错误的图片。

修复链接编辑期间无关的外部更新导致未保存输入丢失的问题；当链接或选中文字发生冲突、无法安全定位时关闭旧表单，避免覆盖其他内容。

修复快速更改选区后使用链接快捷键可能读取旧选区的问题。

修复编辑没有末尾换行的普通文本时可能意外添加末尾换行的问题。

支持在服务端渲染期间导入主模块和 ECharts 模块；编辑器创建和图表渲染仍需在浏览器中进行。

修复表格图表更新失败后继续显示旧结果却没有提示的问题；恢复成功后自动移除提示。

修复粘贴行内文本、Markdown 或富文本时丢失首尾空格的问题，并在跨段落替换时保留格式和空格。

修复快速移动光标后粘贴可能插入到旧位置的问题。

修复编辑器重新聚焦后快速使用键盘移动或扩展文本选区时，光标可能被旧位置覆盖的问题。

修复带边界空格的行内粘贴与前后输入合并为同一撤销步骤的问题。

修复复制链接或代码后，较早请求失败时可能覆盖用户随后通过快捷键或菜单复制、剪切的内容。

销毁编辑器或代码块时取消其未完成的复制回退并释放监听器，避免旧请求覆盖后续剪贴板内容。

浏览器拒绝访问剪贴板接口时，链接和代码复制会尝试可用的回退方式。

宿主页面拦截复制事件、导致回退未能写入剪贴板时，显示复制失败而不是误报成功。

修复自定义 Engine 在渲染期间同步销毁编辑器后，旧的 HTML、表情或图片结果仍可能写入页面的问题。

修复自定义 Engine 渲染图片抛错时编辑器可能无法创建的问题；错误通过 `onError` 报告，图片暂时使用原地址，后续更新可恢复 Engine 的展示结果。

图片使用原地址回退时，继续过滤危险协议，保留安全的图片数据地址。

图片编辑表单会提示不安全的地址并保留原文档，允许修正后保存；上传回调返回不安全地址时立即提示，安全的图片数据地址仍可使用。

上传回调返回非字符串地址时显示失败并允许重试；空的附加参数按未提供处理。

上传回调的名称、尺寸和装饰参数类型错误时忽略对应字段，避免错误类型被写入图片说明或误启用装饰。

上传附加参数读取失败时显示失败并允许重试；读取期间若编辑器已销毁，不再更新旧表单。

修复输入法组合结束事件重复触发或新组合在更新回调中同步开始时，待处理的外部更新可能提前执行或使用错误快照的问题。

代码图表或 Mermaid 更新失败时，明确提示当前保留的是上一次成功渲染的结果；图表错误提示使用主题错误色，便于与正文区分。

要求使用包含剪贴板上下文属性校验修复的 ProseMirror View 版本，降低粘贴恶意 HTML 时的脚本注入风险。

修复 Cherry 复合块正文重复解析可能导致结果不一致的问题。

已缓存的失败恢复文本在编辑器销毁后仍可读取。

修复失败回滚时插件同步修改内容后，读取结果和变更通知可能落后的问题。

外部更新序列化失败且回滚也失败时，错误回调保留两项错误，便于定位原因。

回滚期间插件修改文档时，错误回调可读取被替换前的本地 Markdown，便于应用保存或恢复。

减少编辑器销毁后共享插件对已移除编辑器节点的持有。

销毁完成后释放插件配置中的引擎和业务回调，同时保留延迟清理错误的报告能力。

改进重复文本附近的编辑，结合语法树定位和完整文档校验保留未修改的 Markdown 写法，并在无法确认位置时采用安全回退。
